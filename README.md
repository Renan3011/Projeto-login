## 📖 Sobre o Projeto

Durante as últimas semanas de aula com o Professor [Leonardo Rocha](https://github.com/leonardossrocha), desenvolvemos uma **Tela de Login (Sign-In)** utilizando como base o site oficial do Bootstrap.

O principal objetivo do projeto foi praticar:

- Estruturação com **HTML5**
- Estilização com **CSS3**
- Utilização de **Bootstrap 5**
- Organização e versionamento de código com **Git e GitHub**

Além disso, compreendemos como os frameworks ajudam a:

- Acelerar o desenvolvimento
- Padronizar layouts
- Melhorar a produtividade
- Criar interfaces responsivas

---

## 💡 Implementação do FAQ

Como aplicação prática do conteúdo aprendido, adicionamos uma seção de **Perguntas Frequentes (FAQ)** ao final da página de login, utilizando componentes do Bootstrap.

Essa implementação reforçou conceitos como:

- Componentização
- Responsividade
- Organização visual
- Estrutura semântica
